# 새싹이 캐릭터

모든 좌표는 480×270 viewBox 기준. 오른쪽(+x)을 본다.

## 생김새

| 부위 | 치수 | 그리는 법 |
|---|---|---|
| 머리 | 타원 rx 19, ry 18 | 종이색 채움 + 잉크 1.35. 얼굴은 점 눈 두 개뿐 |
| 눈 | rx 1.5, ry 2.1 | 머리 중심에서 x +8±4 (오른쪽을 봄). 깜빡임 = ry를 0.35까지. 신나면 `^ ^` 호 두 개(펜 1.3)로 바꿈 |
| 새싹 | 줄기 펜 1.1, 높이 ~9 / 잎 두 장 | 머리 꼭대기(hx-1, hy-17.6)에서 올라감. 큰 잎 오른쪽(길이 ~11), 작은 잎 왼쪽(~8). 색 `#86a868`, 테두리 펜 1 |
| 몸통 | 폭 ~23, 높이 30 | 아래가 약간 넓은 둥근 사각 `shape()` (예제의 `body` 경로 그대로) |
| 팔 | `limb(4.2)`, 위팔 12.5 + 아래팔 12 | 어깨는 몸통 위에서 4 아래. 손은 따로 안 그림 |
| 다리 | `limb(5)`, 허벅지 23 + 정강이 24 | 무릎은 `joint(hip, ankle, 23, 24, 1)` (앞으로 굽음) |
| 발 | 잉크 채운 신발 모양 `FOOT` 경로 | 발목에 translate + rotate. 라이브러리 `shoe()`는 이 캐릭터엔 각도가 어색해서 안 씀 |

선은 펜 1.35, 장면 소품은 0.8~1.1. 떨림 필터는 `inkDefs` 후 `feDisplacementMap scale 0.8`.

## 그리는 순서 (뒤 → 앞)

먼 팔 → 먼 다리 → 먼 발 → 몸통 → 가까운 다리 → 가까운 발 → 가까운 팔 → 새싹 줄기 → 새싹 잎 → 머리 → 눈.
줄기를 머리보다 먼저 그려 밑동이 머리에 가려지게 한다. 머리에 무언가 얹을 때(낙엽 등)는 머리보다 나중에 그린다.

## 자세별 기준값과 코드 위치

- **앉기** (`examples/sit.js`): 의자 상판 y 155~163. 엉덩이 (197~199, 154~157), 무릎 (220~222, 154~157), 발목은 무릎에서 `hang(knee, 24, 각도)`. 머리 중심 (200, 103), 몸통 위 y 127. 먼 팔은 그리지 않음.
- **서기·걷기** (`examples/leaves-walk.js`, `examples/autumn.js`): 발 딛는 선 FOOT_Y = 214, 엉덩이 높이 FOOT_Y − 42, 몸통 아래 = 엉덩이 + 3, 몸통 위 = 아래 − 30, 머리 중심 = 몸통 위 − 24, 머리 x = 몸 x + 1.5.
  - 걷기 위아래 흔들림 −1.6·sin(π·s) (발 딛는 중간에 가장 높음)
  - 깡총: 착지 직후 2.2 눌렸다가 s 0.4~1.0 동안 최대 11 떠오름, 뒷발은 s 0.48에 뗌
- **새싹 흔들림**: 몸이 오르내리는 속도와 바람을 목표로 하는 스프링(강성 60, 감쇠 7). 바람 세기 1일 때 +6 정도 휨.
- **물들기** (`autumn.js`의 `mix`, `SPROUT_A/B`): 초록 → 연두 `#b7b35c` → 노랑 `#e2b350` → 주황 `#d9824e`/빨강 `#c9604a`.
